# RAP DJ SET (PWA)
Статический сайт без сборки. Все BPM/тональности в нём — demo-примеры.

## Деплой на Replit
1. Replit → Create Repl → Static HTML, загрузи все файлы этой папки.
2. Run — проверь превью.
3. Deploy → Static → Deploy. Получишь публичную ссылку *.replit.app.

## Установка на телефон
- iPhone: Safari → Поделиться → «На экран "Домой"».
- Android/Chrome: меню ⋮ → «Установить приложение».
- Mac Safari: Файл → Добавить в Dock.

## Обновление
Сайт сначала берёт свежую версию из сети. При крупных изменениях подними версию V в sw.js.
